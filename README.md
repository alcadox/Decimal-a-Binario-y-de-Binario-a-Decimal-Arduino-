# 💡 Guía Breve – Proyecto con Arduino

> Una referencia rápida para comprender el funcionamiento del sistema de **introducción de números binarios y decimales** con pulsadores y LEDs.

---

## ⚙️ Descripción General

Este proyecto utiliza un **Arduino** junto con **pulsadores**, **interruptores** y **LEDs** para introducir y visualizar números en **binario** y **decimal**.  
Cada componente cumple una función específica que te ayudará a interactuar correctamente con el sistema.

---

## 🧭 Instrucciones de Uso

### 🔴 Pulsador del LED Rojo  
- Indica que **has terminado** de introducir el número (ya sea binario o decimal).  
- Úsalo una vez que estés seguro de haber completado la entrada.

---

### ⚪ Pulsador del LED Blanco  
- Se utiliza para **introducir el número en formato decimal**.  
- Cada pulsación puede representar un incremento o una acción dentro del modo decimal.

---

### 🔁 Botón de *Reset* (Arduino)  
- Reinicia el sistema completamente.  
- Al presionarlo, **todo vuelve al estado inicial**, permitiendo comenzar desde cero.

---

### ⚙️ Interruptor  
- Controla la **dirección o el modo** de funcionamiento:  
  - **ON → Izquierda**  
  - **OFF → Derecha**

---

### 🟡 LED Amarillo  
- Indica el **número decimal que debes convertir e introducir en binario**.  
- Sirve como **referencia visual** durante el ejercicio o demostración.

---

## 💬 Notas Finales

- Asegúrate de **seguir el orden de las acciones** para evitar errores de interpretación.  
- Comprueba las **conexiones** antes de iniciar la prueba.  
- Ideal para proyectos educativos o demostraciones de **conversión binario-decimal** con Arduino.
